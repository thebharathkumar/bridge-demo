Verdicts

How a verdict is reached

  1. Hard criteria, in code. Loan size, excluded industry, geography, LTV, exposure cap. Arithmetic and set membership, never a judgment call. Any failure is Not Eligible, cited to the exact criterion.
  2. Margin check. A deal that breaks no rule but lands within 10% of a loan-size bound, 2 points of the LTV cap, or 10% of an exposure cap is Borderline regardless of how it reads otherwise.
  3. Soft criteria. Only for deals that cleared the hard filter. Operator experience, risk appetite language. This pass can move a deal to Borderline, but it can never produce a Not Eligible: a preference is not a rule.
